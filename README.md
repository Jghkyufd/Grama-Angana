# Grama-Angana – Community Space Manager

## 📌 Project Overview

Grama-Angana is an Android application developed to manage village community halls such as Anganas and Samudaya Bhavanas. The app helps citizens check hall availability, request bookings, view community events, and contribute towards maintenance needs. It aims to improve transparency, increase utilization of public infrastructure, and encourage community participation.

---

# 🎯 Problem Statement

Community halls in villages are often underutilized because people are unaware of:

* Hall availability
* Booking status
* Key holder details
* Maintenance requirements

This results in poor usage and gradual decay of public infrastructure.

---

# 💡 Proposed Solution

Grama-Angana provides a digital platform where users can:

* View booked and available slots
* Request hall bookings
* See community events
* Contribute towards maintenance funds

The application creates a transparent and organized management system for public spaces.

---

# ✨ Features

## 📅 Event Calendar

* Displays booked and free slots
* Prevents double booking
* Helps users check availability instantly

## 📝 Booking Request System

* Users can request a hall slot
* Requests are sent to the Panchayat/admin

## 💰 Maintenance Jar

* Displays items needed for maintenance
* Shows funding progress using a progress bar
* Allows community support and contributions

## 📢 Event Board

* Shows current and upcoming events
* Keeps the community informed

# 🔄 System Workflow

1. User opens the app
2. Checks hall availability using the calendar
3. Sends booking request
4. Admin verifies and approves request
5. Booking status updates in real time
6. Users can view events and contribute to maintenance
